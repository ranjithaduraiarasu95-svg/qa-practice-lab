Sign in

The page under test. Try to break it.

Scenario 1: Login form

Level: Beginner

Valid credentials

Email: tester@qalab.dev
Password: Test@1234

Skills practiced: locators (id, name, data-testid), typing, clicking, asserting text, checking element visibility and attributes.

Test cases to write

Valid login

Enter valid email and password, click Sign in. Expect the welcome panel and a Log out button.

Wrong password

Valid email, wrong password. Expect the message “Invalid email or password.” and no welcome panel.

Unknown email

Use nobody@example.com. Same generic error message as a wrong password.

Empty fields

Click Sign in with both fields empty. Expect “Email is required.” and “Password is required.”

Email format

Enter testerqalab.dev. Expect “Enter a valid email address.”

Show / hide password

Type a password, click Show. The input type changes from password to text, and the button text becomes Hide.

Whitespace around email

Enter a valid email with spaces before and after. Expect login to succeed (input is trimmed).

Case sensitivity

Email is not case sensitive. Password is case sensitive.

Remember me

Check the box, log in, then log out. The email field should come back pre-filled. Uncheck it and the field stays empty.

Logout

After logging in, click Log out. The form returns, and the password field is empty.
